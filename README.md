# 王陆语料库 · 听写练习 v6

个人听写练习页（纯前端，单文件，记录只存在你自己的浏览器里）。

- 只判「做到的范围」：没做的词不进生词本、不计成绩
- 生词本：显示你写错的拼写、正确拼写、释义，每词带发音，可连播，旁边有手写区（抄写 / 默写）
- 错题测试：连续 2 次写对＝掌握
- 草稿自动保存、数据导出 / 导入

基于 pipitang233/wanglu-dictation-app 的 v5 修改。语料版权归《雅思王听力语料库》原作者，仅供个人学习使用。

## 数据安全（2026-10-10 加）
- 云同步：连接私有仓库 `wanglu-dictation-data`，听写记录 + 生词本自动同步，每次同步留一个历史版本
- 本机快照：IndexedDB 每天一份（保留 30 天），清空 / 导入 / 恢复前自动存一份
- 记录被清空时：云端有数据会自动恢复；没有云端时首页提示用本机快照恢复
